4) varin-cli commands using these files
---------------------------------------
From:
cd "x:\EziLearnings-Workspace\EziLearnings\Varin Video Generator\Varin"

Single scene render:
cargo run --release -p varin-cli -- render --input ".\sample_scene.json" --output ".\output\sample-scene.mp4" --ffmpeg ffmpeg

Storyboard render:
cargo run --release -p varin-cli -- render-storyboard --input ".\sample_storyboard.json" --output ".\output\sample-storyboard.mp4" --ffmpeg ffmpeg

Validate:
cargo run --release -p varin-cli -- build --input ".\sample_storyboard.json"

Prompt generation:
cargo run --release -p varin-cli -- prompt-storyboard --input ".\prompt_input.json"


5) VarinStudio API request body samples
---------------------------------------
POST /api/validate body:
{
  "inputJson": "{ ... your scene or storyboard JSON as string ... }"
}

POST /api/render body:
{
  "inputJson": "{ ... your scene or storyboard JSON as string ... }",
  "outputPath": "x:\\EziLearnings-Workspace\\EziLearnings\\Varin Video Generator\\Varin\\output\\api-render.mp4",

6) PowerShell quick API example
-------------------------------
# Start VarinStudio first (npm run dev in VarinStudio folder), then:

$json = Get-Content ".\sample_storyboard.json" -Raw

$validateBody = @{ inputJson = $json } | ConvertTo-Json -Depth 40
Invoke-RestMethod -Method POST -Uri "http://localhost:8787/api/validate" -ContentType "application/json" -Body $validateBody

$renderBody = @{
  inputJson = $json
  outputPath = "x:\EziLearnings-Workspace\EziLearnings\Varin Video Generator\Varin\output\api-sample.mp4"
  ffmpegPath = "ffmpeg"
  cpuRatio = 0.7
  ramRatio = 0.65
} | ConvertTo-Json -Depth 40

$job = Invoke-RestMethod -Method POST -Uri "http://localhost:8787/api/render" -ContentType "application/json" -Body $renderBody
$jobId = $job.jobId
Invoke-RestMethod -Method GET -Uri "http://localhost:8787/api/job/$jobId"
