Varin Architecture Guide
========================

This document explains architecture and gives diagram text.
You can keep exported architecture images in the same folder as this file.

Suggested image filenames (if you export diagrams):
- VARIN_ARCHITECTURE_OVERVIEW.png
- VARIN_RENDER_PIPELINE.png
- VARIN_STORYBOARD_PIPELINE.png


1) High-level architecture
--------------------------
Two-part system:

1. Varin (Rust engine + CLI)
   - varin-core: data model, validation, timeline resolution
   - varin-render: frame rasterization + ffmpeg encoding
   - varin-cli: orchestration commands (render, storyboard, build, sync, etc.)

2. VarinStudio (React + Node API)
   - React UI for prompt/JSON workflow
   - Express server calling varin-cli using cargo run

4) Storyboard pipeline detail
-----------------------------
1. Read storyboard JSON (explicit scenes or legacy brief mode)
2. For each scene:
   - use scene_path, or
   - compile scene_explanatory DSL to Scene
3. Validate Scene objects
4. Prepare narration audio (edge-tts + ffprobe duration)
5. Retiming to fit narration-aware pacing
6. Render each scene segment (raw mp4)
7. Mux segment with audio
8. Concat all segments into final mp4
9. Write SRT captions (caption or narration fallback)


5) Render internals
-------------------
- varin-render chooses backend:
  - default: skia CPU renderer
  - optional: wgpu backend for compatible primitive subset
- Frames are generated in chunks (RAM-aware), in parallel (CPU-aware)
- RGBA frames are streamed to ffmpeg stdin
- Encoder selection:
  - h264_nvenc if available and supported
  - otherwise libx264

7) Operational caveats
----------------------
- README/example list may not exactly match current files in examples/
- sync timing can differ from final retimed storyboard render timing
- edge-tts availability/network can affect narration stage
- cache location depends on current working directory unless VARIN_CACHE_DIR is set
