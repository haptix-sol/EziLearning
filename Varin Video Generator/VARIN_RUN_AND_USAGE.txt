Varin - Run and Usage Guide (Get Results First)
================================================

This guide is optimized for getting your first successful output quickly.

Project paths
-------------
- Engine (Rust CLI): Varin Video Generator/Varin
- UI + API wrapper:   Varin Video Generator/VarinStudio


1) Fastest way to get first result (varin-cli)
----------------------------------------------
Open PowerShell:

1. Go to Varin:
   cd "x:\EziLearnings-Workspace\EziLearnings\Varin Video Generator\Varin"

2. Build once:
   cargo build --release

3. Render a small scene:
   cargo run --release -p varin-cli -- render --input ".\examples\wgpu_rect_core_demo.json" --output ".\output\first-scene.mp4" --ffmpeg ffmpeg

Expected result:
- Output file: .\output\first-scene.mp4


2) First storyboard result (multi-scene video)
----------------------------------------------
From the same Varin folder:

cargo run --release -p varin-cli -- run storyboard --input ".\examples\java_oops_full_explainer.json" --output ".\output\first-storyboard.mp4" --ffmpeg ffmpeg

Expected result:
- Output file: .\output\first-storyboard.mp4
- Captions file (if captions exist): .\output\first-storyboard.srt


3) Core varin-cli commands you will use
---------------------------------------
Render one scene:
cargo run --release -p varin-cli -- render --input "<scene.json>" --output "<out.mp4>" --ffmpeg ffmpeg

Render storyboard:
cargo run --release -p varin-cli -- render-storyboard --input "<storyboard.json>" --output "<out.mp4>" --ffmpeg ffmpeg

Run aliases:
cargo run --release -p varin-cli -- run scene --input "<scene.json>" --output "<out.mp4>"
cargo run --release -p varin-cli -- run storyboard --input "<storyboard.json>" --output "<out.mp4>"

Validate inputs:
cargo run --release -p varin-cli -- build --input "<scene-or-storyboard.json>"

Generate captions timeline from storyboard durations:
cargo run --release -p varin-cli -- sync --input "<storyboard.json>" --output "<out.srt>"

Generate prompt text for LLM storyboard creation:
cargo run --release -p varin-cli -- prompt-storyboard --input "<prompt-input.json>"

Materialize storyboard scenes into JSON scene files:
cargo run --release -p varin-cli -- materialize-scenes --input "<storyboard.json>" --out-dir "<dir>"


4) Important runtime flags (performance and stability)
------------------------------------------------------
You can add these to render commands:

--cpu-ratio <0..0.70>      Example: --cpu-ratio 0.70
--ram-ratio <0..0.70>      Example: --ram-ratio 0.65
--max-threads <N>          Example: --max-threads 8
--no-hw-encode             Disable NVENC auto-detection
--no-live-monitor          Disable adaptive chunk monitor
--benchmark-fast           Favor speed profile
--force-wgpu-backend       Force wgpu for compatible primitive subset


5) Use VarinStudio API (Varin API wrapper)
------------------------------------------
Varin itself is a CLI. The "API" is exposed by VarinStudio server.

Start VarinStudio:

cd "x:\EziLearnings-Workspace\EziLearnings\Varin Video Generator\VarinStudio"
npm install
npm run dev

Default endpoints:
- UI:  http://localhost:5175
- API: http://localhost:8787

Key API routes:
- GET  /api/config
- POST /api/llm-prompt/storyboard
- POST /api/validate
- POST /api/render
- GET  /api/job/:id


6) API examples (PowerShell)
----------------------------
Get config:
Invoke-RestMethod -Method GET -Uri "http://localhost:8787/api/config"

Validate JSON:
$body = @{
  inputJson = (Get-Content ".\sample.json" -Raw)
} | ConvertTo-Json -Depth 20
Invoke-RestMethod -Method POST -Uri "http://localhost:8787/api/validate" -ContentType "application/json" -Body $body

Start render:
$renderBody = @{
  inputJson = (Get-Content ".\sample.json" -Raw)
  outputPath = "x:\EziLearnings-Workspace\EziLearnings\Varin Video Generator\Varin\output\api-output.mp4"
  ffmpegPath = "ffmpeg"
  cpuRatio = 0.7
  ramRatio = 0.65
} | ConvertTo-Json -Depth 20

$job = Invoke-RestMethod -Method POST -Uri "http://localhost:8787/api/render" -ContentType "application/json" -Body $renderBody
$jobId = $job.jobId

Poll job:
Invoke-RestMethod -Method GET -Uri "http://localhost:8787/api/job/$jobId"


7) Troubleshooting
------------------
If ffmpeg not found:
- Install ffmpeg and ensure ffmpeg/ffprobe are on PATH, or pass --ffmpeg path.

If TTS fails:
- Install edge-tts:
  py -m pip install --user edge-tts

If Rust build fails on linker tools:
- Install Visual C++ Build Tools workload.

If validation fails:
- Run build preflight first:
  cargo run --release -p varin-cli -- build --input "<file.json>"


8) Where output and cache go
----------------------------
- Outputs: Varin/output
- Storyboard work dirs: temporary .varin_storyboard_* near output folder
- Cache: .varin_cache in current working dir (or VARIN_CACHE_DIR if set)
